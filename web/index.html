Load your Cybiko Xtreme dumps

The emulator needs the Xtreme's boot ROM (32 KB, such as cyrom150.bin) and flash (512 KB, such as cyos_v1508.bin). They are not on this site: pick your own files. They stay in this browser and are never uploaded.

PC keys: letters, Enter, Esc, Space, arrows, Tab, Backspace = Del, Shift, Ctrl = Fn, F1-F7, F8 or Home = Select, F9 = Help, F10 or Insert = Ins, F11 = Menu, F12 = On/Off, [ ] = ( ), / = !. Drop .app files on the page to install them.

Settings

Gives the CyWIG gate its internet and links this Cybiko to others in the same room. Empty: no internet, radio only between tabs of this browser.

Cybikos in the same room hear each other (Chat, games). Tabs of this browser share it without the relay.
