Start your Cybiko

The emulator runs the Cybiko's own firmware: its boot ROM and CyOS 1.5.08. One click fetches both from cybiko-roms on GitHub, and this browser keeps them.

The emulator runs the first Cybiko's own firmware: its boot ROM, from MAME's cybikov1 set as ReBiko ships it, and CyOS 1.2.57, the last CyOS for it (Cybiko's System Pack 57, which knows the memory card), or the dump's CyOS 1.2.46. One click fetches them from cybiko-roms on GitHub, and this browser keeps them.

Use my own files instead

Pick the boot ROM, cyrom150.bin (32 KB), and the flash, cyos_v1508.bin (512 KB), or MAME's Cybiko ROM set (cybikov1.zip), from which the page takes those two. A CyOS update (*.boot) is optional and installed on start. Nothing is uploaded.

Pick the boot ROM, cyrom112.bin (32 KB), and the flash, flash_v1246.bin (528 KB), or a zip with them: MAME's cybikov1.zip, or a ReBiko release, which has them as roms/boot.bin and roms/flash.bin. A saved flash_saved.bin (1 MB) works as the flash too. Nothing is uploaded.

MP3 player:

PC keys: letters, digits and punctuation as on the PC, Enter, Esc, Space, arrows, Tab, Backspace, Delete = Del, Shift, Ctrl = Fn, F1-F7, F8 or Home = Select, F9 = Help, F10 or Insert = Ins, F12 = On/Off. The Classic has no RAM disk or cartridge: CyOS 1.2 keeps its files in its flash, and Add files (or dropping files on the page) copies them there through CyOS's console, as Cybiko's PC software did. The memory card (Settings) needs CyOS 1.2.57: Install CyOS 1.2.57 puts it on from Cybiko's System Pack 57, as Cybiko's AutoUpdate did; the File Manager then shows the card as Card Flash. The MP3 player (Settings: Slot) needs CyOS 1.2.57 and its software, MP3.app, MP3.dl and mp3_control.dl:

PC keys: letters, Enter, Esc, Space, arrows, Tab, Backspace = Del, Shift, Ctrl = Fn, F1-F7, F8 or Home = Select, F9 = Help, F10 or Insert = Ins, F11 = Menu, F12 = On/Off, [ ] = ( ), / = !. Drop .app or other files on the page (or use Add files) to put them on the Cybiko; it restarts to take them.

Get apps, games and the MP3 player

Tick what you want and press Install: the files come from cybiko-roms, copies of the Cybiko CDs. The Cybiko restarts to take them, and new apps appear at the end of the Main desktop.

More games and apps: the cybiko.net mirror, Kerry Brown's archive and Jake Kussmaul's collection. Download them, then drop them on the page or use Add files to the Cybiko; .cap and .csu installers are unpacked. Everything on the Cybiko is in Settings → Files on the Cybiko.

The MP3 cartridge's card. MP3s and MXD clips (.app files made by the converters), as you would put them on the real card. Kept in this browser; the Cybiko sees them after a restart. What the Cybiko does on the card (its File Manager's Delete, files it writes) is kept too. The cartridge's software (MP3.cap) goes on the Cybiko, not the card: the page moves it there if you add it here.

Card:

    Replaces the flash with a fresh CyOS: the files on it go (Download backup first). To keep them and go from 1.2.46 to 1.2.57, use Install CyOS 1.2.57 instead.

    The memory card: 256 KB RAM and 1 MB flash (the Cybiko 1Mb Memory Card). CyOS 1.2.57 uses it (Install CyOS 1.2.57); CyOS 1.2.46 does not see it. What CyOS writes on it is kept in this browser.

    The MP3 player (CY65P10): its SmartMedia card is the card above: MP3s, and apps CyOS runs from it (File Manager, SMC), such as MXD clips made for Classic + Xtreme. It needs CyOS 1.2.57 and the player's software (the button under the keyboard); then MP3 on the desktop plays the card, and the player's own buttons show above the keyboard. Emulated from what Cybiko's software does: the player's firmware was never dumped, and its FM radio and voice recorder are not there.

    The Classic's backup is its flash (flash_saved.bin, as the board saves it): CyOS and its files together.
